# AgenticCPS 快速开始

本文面向首次运行 AgenticCPS 的开发者，覆盖本地依赖、数据库初始化、后端与前端启动以及 Docker 部署。功能说明请先阅读 [README](../README.md)，模块和接口入口见 [项目地图](./project-map.md)。

## 1. 环境要求

| 组件 | 版本要求 |
| --- | --- |
| JDK | 17 或 21（推荐 21） |
| MySQL | 5.7 或 8.0+ |
| Redis | 5.0+ |
| Maven | 3.8+ |
| Node.js | 16+（admin-vue3）/ 20+（admin-uniapp） |
| pnpm | 8.6+（admin-vue3）/ 9+（admin-uniapp） |

本地后端默认端口为 `48080`，MySQL 默认库名为 `cps`，Redis 默认地址为 `127.0.0.1:6379`。请按本机环境修改 `backend/qiji-server/src/main/resources/application-local.yaml`，不要把本地凭证用于生产。

## 2. 获取代码

```bash
git clone https://github.com/zhuangpengLI/AgenticCPS.git
cd AgenticCPS
```

## 3. 初始化数据库

在 MySQL 中按以下顺序执行：

1. `backend/sql/mysql/ruoyi-vue-pro.sql`：系统基础表。
2. `backend/sql/module/cps-all-in-one.sql`：新库使用的 CPS 全量表、菜单、权限和种子数据。
3. 已有环境升级时，改为执行 `backend/sql/module/cps-update.sql` 中尚未执行的增量段；不要重复导入全量脚本。

CPS 增量脚本必须追加到文件末尾并保留修改时间记录。金额以分为单位，生产环境请先备份并核对租户数据。

## 4. 启动后端

```bash
cd backend
mvn clean compile
mvn spring-boot:run -pl qiji-server -Dspring-boot.run.profiles=local
```

服务启动后，管理端 API 前缀为 `/admin-api`，会员端 API 前缀为 `/app-api`。主应用入口为 `com.qiji.cps.server.QijiServerApplication`。

## 5. 启动前端

### 管理后台（admin-vue3）

```bash
cd frontend/admin-vue3
pnpm install
pnpm dev
```

常用检查：

```bash
pnpm ts:check
pnpm lint:eslint
pnpm e2e
```

### 移动管理端（admin-uniapp）

```bash
cd frontend/admin-uniapp
pnpm install
pnpm dev:h5
```

检查与构建：

```bash
pnpm type-check
pnpm lint
pnpm build:prod
```

### 商城移动端（mall-uniapp）

该端主要通过 HBuilderX 运行 H5；当前仓库仅提供格式化脚本：

```bash
cd frontend/mall-uniapp
npm run prettier
```

## 6. Docker 部署

在源码机生成可复制的部署目录：

```bash
cd backend/script/docker
bash build-package.sh
```

将生成的 `backend/script/docker` 目录复制到部署服务器后执行：

```bash
bash deploy.sh
bash deploy.sh status
bash deploy.sh logs server
bash deploy.sh down
```

默认端口映射：后端 `48080:48080`、管理前端 `8080:80`、MySQL `3306:3306`、Redis `6379:6379`。生产部署前请修改 `docker.env` 中所有 `ChangeMe_` 默认密码，并确认 `application-prod.yaml` 的外部服务配置。

Windows 环境可使用同目录的 `build-package.ps1`；如需发布商城 H5，请安装 HBuilderX CLI，或通过 `-HBuilderXCliPath`、`SHOPRO_H5_CLI` / `HBUILDERX_CLI_PATH` 指定路径。

## 7. CPS 改动的最小验证

后端 CPS 变更建议先运行目标模块测试：

```bash
cd backend
mvn test -pl qiji-module-cps/qiji-module-cps-biz -am \
  -Dtest=CpsRebateTokenExchangeServiceImplTest \
  "-Dsurefire.failIfNoSpecifiedTests=false"
```

管理后台变更至少运行：

```bash
cd frontend/admin-vue3
pnpm ts:check
pnpm e2e
```

涉及资金、订单、归因、OpenAPI 或 MCP 的改动，还应补充对应的幂等、租户隔离、可信会员上下文和审计日志断言。完整流程见 [Codex Agentic 开发流程](./codex-agentic-development-workflow.md)。

- 平台配置中心：管理后台“联盟配置 → 平台配置中心”，前端路由 `/cps-config/platform-onboarding`。
- MCP 端点：`/mcp/cps`；工具清单和调用示例见 [MCP Server 使用指南](./agentic-cps-mcp-server-guide.md)。
- Docker 详细说明：`backend/script/docker/Docker-HOWTO.md`。
- 供应商配置与真实接口测试： [大淘客与好单库配置及接口测试指南](./大淘客与好单库配置及接口测试指南.md)。

# AgenticCPS 业务接口只读验收（2026-10-29）

## 使用范围

`script/ci/cps_business_readonly_smoke.py` 仅针对**本机已有的** `127.0.0.1:18080` 运行实例，调用七组只读或明确拒绝匿名访问的接口：管理后台、H5、启用的装修模板、空搜索参数校验、匿名转链拦截、匿名订单查询拦截、匿名管理权限拦截。

运行：

```bash
python3 script/ci/cps_business_readonly_smoke.py
```

在腾讯云部署环境，也可以使用部署目录下同名脚本（若有）。脚本不登录、不读取数据库密码、不写业务记录、不调用联盟搜索 API、不执行真实推广转链、下单、入账或提现。要求服务在该机器的 loopback 端口 `18080` 已运行，且租户 1 有启用的 H5 装修模板。

## 已观察结果

在 `VM-0-8-ubuntu` 的本地端口上，2026-10-29 实际运行：**7/7 通过**。注意：HTTP 200 可能包含 JSON 业务错误码；脚本同时检查后者，不能把 HTTP 200 当作业务成功。

## 下一阶段的受控顺序

1. 选择一个**已取得合法联盟权限**的平台；先检查平台对应供应商的官方文档、授权范围、实际 API 能力及费用。
2. 通过后台 `CPS / 平台配置中心` 的平台 → 供应商 → 推广位 → 返利规则 → 校验/连接测试流程录入真实配置。不要将密钥放入 Git、聊天记录或测试截图。
3. 在隔离测试账号下验证搜索、详情、券、转链；核对推广位、渠道归因参数，确认不借用别人的推广身份。
4. 使用联盟平台允许的真实测试订单或官方沙箱，观察回传、订单归因、冻结、结算、退款冲回和幂等审计；资金相关步骤需单独批准。
5. 单独进行会员访问控制、租户隔离和账本对账，再考虑开放生产入口。

未配置真实供应商及推广位前，不应启用真实提现或对外宣布返利到账。

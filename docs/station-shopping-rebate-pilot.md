# 驿站推广购物返利：测试阶段交付

本期范围为驿站邀请消费者查券购物；返利来源为联盟确认结算的商品佣金。
不包含快递寄件计费、快递服务商回调或寄件差价。

## 本期实现

- 邀请页用现有 lime-painter 绘制真实推广二维码，链接保留 /h5/ 等部署子目录。
- 商品入口接收 inviteCode。未登录时暂存 7 天，会员会话校验成功后调用 CPS 推荐关系接口。
- 数据库以“尚未绑定”为条件执行一次原子绑定；并发竞争只有一个成功者，重试不会重复累计团队人数。
- 暂存期间采用首次触达邀请码，后续访问不覆盖；后端仍负责判断邀请码、租户、会员身份、已有推荐人和循环关系。
- 登录和生成购买链接并发触发时，共用同一次绑定请求。网络失败保留待重试的邀请码，生成购买链接前再次确认。
- 后端明确拒绝绑定时清除该邀请码，不声称归因成功；已有推荐关系保持后端判定。
- 不再承诺“首单终身绑定”或每次下单必得佣金。联盟未结算、退款、冻结资格和既有绑定均会影响收益。
- 复用现有推广中心、团队与分佣明细。未新增另一套资金账户，也未修改全局分佣默认比例。

## 单驿站试验配置

使用隔离测试租户和测试会员。管理端先确认驿站推广员状态为有效，再让新会员经邀请码绑定。
可在测试租户的分账规则中试验以下比例（仅示例，不是已启用的经营定价）：

| 项目 | 示例比例 |
| --- | --- |
| 平台留存 | 联盟总佣金的 20% |
| 消费者自购返利 | 扣平台留存后净佣金的 75% |
| 一级驿站代理 | 净佣金的 25% |
| 二级分佣 | 0% |

联盟确认总佣金 100 元时，示例结果为消费者 60 元、驿站 20 元、平台 20 元。
规则匹配目前按平台和消费者会员等级，不是按驿站独立签约价；同一测试租户内应明确该规则的作用范围。
多驿站独立协议、驿站资料/审核、专属费率和结算报表为后续工作，不应当作本期已完成。

## 仍需隔离环境人工验收

1. 扫描实际生成的二维码，确认进入正确 H5 子目录及商品页。
2. 新会员登录后检查推荐关系，随后生成购物链接并使用供应商测试订单验证归因。
3. 重复扫描、不同邀请码、已绑定用户、无效或冻结推广员不得覆盖已有合法归因。
4. 使用测试数据演练已结算、冻结、解冻、退款、已提现后欠款和重复事件，核对每一笔资金台账。
5. 测试真实联盟订单需可用的供应商测试账户和配置；Mock/H2 测试不能代替联盟实单验收。
